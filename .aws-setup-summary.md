## ⚙️ Configuração AWS

### Profiles Criados

```ini
# ~/.aws/config
[default]
region = us-east-1
output = json

[profile ysh-production]
region = us-east-1
output = json
```

### Credenciais (Pendente)

⚠️ **Ação Necessária**: Configure as credenciais AWS

```powershell
# Opção 1: Via comando interativo
aws configure --profile ysh-production

# Opção 2: Via arquivo manual
# Edite: $env:USERPROFILE\.aws\credentials
```

Formato do arquivo `credentials`:
```ini
[ysh-production]
aws_access_key_id = YOUR_ACCESS_KEY
aws_secret_access_key = YOUR_SECRET_KEY
```

## 🐳 LocalStack - Ambiente de Desenvolvimento

### Iniciar LocalStack

```powershell
# Via Docker Compose
cd docker
docker-compose -f docker-compose.localstack.yml up -d

# Verificar status
docker-compose -f docker-compose.localstack.yml ps
```

### Inicializar Recursos LocalStack

```bash
# Executar script de inicialização
bash scripts/localstack-init.sh
```

### Comandos LocalStack

```powershell
# S3
awslocal s3 mb s3://test-bucket
awslocal s3 ls

# Secrets Manager
awslocal secretsmanager create-secret --name test-secret --secret-string "test-value"
awslocal secretsmanager get-secret-value --secret-id test-secret

# DynamoDB
awslocal dynamodb list-tables
```
