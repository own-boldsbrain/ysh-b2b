### Calculadora Rápida

**Geração Mensal:**
```
kWh/mês = kWp × HSP × 30 × 0.80
```

**Payback:**
```
Anos = Investimento / (Geração Anual × Tarifa)
```

**Área Necessária:**
```
m² = (kWp / Eficiência %) × 6
```
