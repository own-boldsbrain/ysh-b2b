## 🌟 Visão Geral

### O que são Kits Solares?

Kits solares são **conjuntos completos** de equipamentos fotovoltaicos pré-dimensionados para diferentes aplicações, contendo todos os componentes necessários para geração de energia solar:

#### Componentes Principais
1. **Painéis Fotovoltaicos** - Geração de energia
2. **Inversor** - Conversão DC/AC e gerenciamento
3. **Estrutura de Fixação** - Montagem conforme tipo de telhado
4. **Cabos e Conectores** - Interconexão elétrica
5. **Proteções Elétricas** - String box, DPS, disjuntores
6. **Acessórios de Instalação** - Materiais complementares

#### Componentes Opcionais (Kits Híbridos/Off-Grid)
- **Baterias** - Armazenamento de energia
- **Controlador de Carga** - Gerenciamento de baterias
- **Backup Power** - Sistema de redundância

## 📊 Categorização de Kits

### 1️⃣ Por Tipo de Sistema

#### 🔌 On-Grid (Grid-Tie)
**Conexão com rede elétrica**

**Características:**
- Conexão direta com a rede da concessionária
- Compensação de energia (créditos)
- Sem armazenamento de energia
- Menor custo de investimento
- ROI mais rápido (3-5 anos)

**Faixas de Potência:**
- **Micro**: 0,16 - 3,0 kWp (residencial pequeno)
- **Pequeno**: 3,0 - 10,0 kWp (residencial médio/comercial pequeno)
- **Médio**: 10,0 - 30,0 kWp (comercial/pequena indústria)
- **Grande**: 30,0 - 50,0 kWp (industrial/comercial grande)

**Aplicações:**
- Residências
- Comércio
- Pequenas indústrias
- Estabelecimentos conectados à rede

#### 🔋 Off-Grid (Autônomo)
**Sistema isolado sem conexão com rede**

**Características:**
- 100% autônomo
- Armazenamento obrigatório (baterias)
- Geração e backup independentes
- Maior custo de investimento
- Ideal para locais remotos

**Faixas de Potência:**
- **Micro**: 0,16 - 1,0 kWp (iluminação/pequenos dispositivos)
- **Pequeno**: 1,0 - 5,0 kWp (residências pequenas)
- **Médio**: 5,0 - 15,0 kWp (residências/fazendas)
- **Grande**: 15,0 - 50,0 kWp (aplicações industriais remotas)

**Aplicações:**
- Propriedades rurais isoladas
- Locais sem acesso à rede
- Telecomunicações
- Bombeamento de água
- Iluminação pública remota

#### ⚡ Híbrido (Hybrid)
**Melhor dos dois mundos**

**Características:**
- Conexão com rede + armazenamento
- Backup automático em quedas de energia
- Uso otimizado (bateria + rede)
- Independência energética gradual
- Maior custo mas máxima flexibilidade

**Faixas de Potência:**
- **Pequeno**: 3,0 - 8,0 kWp (residencial com backup)
- **Médio**: 8,0 - 20,0 kWp (comercial com alta demanda)
- **Grande**: 20,0 - 50,0 kWp (industrial crítico)

**Aplicações:**
- Residências com backup crítico
- Comércio/indústria com processos sensíveis
- Hospitais, clínicas
- Data centers
- Telecomunicações

#### 🏠 Residencial (B1/B2)
**Classe Tarifária:** B1 (residencial) / B2 (rural)

**Características:**
- Tarifa: R$ 0,75 - R$ 0,95/kWh
- Monofásico/Bifásico (127/220V)
- Sistemas 1-10 kWp (típico)
- Microinversores ou string pequenos
- Telhados cerâmico/metálico/fibrocimento

**Faixas de Consumo:**
- **Baixo:** 150-300 kWh/mês → 2-4 kWp
- **Médio:** 300-600 kWh/mês → 4-7 kWp
- **Alto:** 600-1.000 kWh/mês → 7-12 kWp

#### 🏢 Comercial (B3)
**Classe Tarifária:** B3 (comercial)

**Características:**
- Tarifa: R$ 0,80 - R$ 1,10/kWh
- Trifásico (220/380V)
- Sistemas 5-30 kWp (típico)
- Inversores string médios
- Lajes/telhados metálicos

**Faixas de Consumo:**
- **Pequeno:** 500-1.500 kWh/mês → 5-15 kWp
- **Médio:** 1.500-3.000 kWh/mês → 15-25 kWp
- **Grande:** 3.000-5.000 kWh/mês → 25-40 kWp

#### 🏭 Industrial (A4/B3)
**Classe Tarifária:** A4 (industrial MT) / B3 (industrial BT)

**Características:**
- Tarifa: R$ 0,70 - R$ 1,20/kWh (demanda + consumo)
- Trifásico industrial (220/380/440V)
- Sistemas 20-50+ kWp
- Inversores centrais ou múltiplos strings
- Estruturas solo/telhado industrial

**Faixas de Consumo:**
- **Pequena:** 2.000-5.000 kWh/mês → 20-35 kWp
- **Média:** 5.000-10.000 kWh/mês → 35-60 kWp
- **Grande:** 10.000+ kWh/mês → 60+ kWp (múltiplos sistemas)

## 💼 Regras de Negócio

### 🎯 Dimensionamento de Sistemas

#### Metodologia de Cálculo

**1. Análise do Consumo**
```
Consumo Médio Mensal (kWh) = Σ(12 meses) / 12
```

**2. Correções e Fatores**
```
Fator Segurança = 1,15 - 1,45 (conforme perfil)
Fator Sombreamento = 0,90 - 0,95
Fator Temperatura = 0,90 - 0,95
Fator Sujidade = 0,95 - 0,98
```

**3. Potência Necessária**
```
Potência (kWp) = (Consumo × Fator Segurança) / (HSP × 30 × Fatores Correção)

Onde:
- HSP = Horas de Sol Pleno (média região)
- 30 = dias do mês
- Fatores Correção = produto dos fatores acima
```

**4. Seleção de Kit**
- Escolher kit com potência ≥ Potência Necessária
- Considerar margem 5-10% para expansão
- Verificar compatibilidade inversor/painéis

#### Níveis de Dimensionamento

**🟢 Geração Moderada (115%)**
- **Target:** Consumidores conservadores
- **Característica:** Suprimento básico com pequena margem
- **Vantagem:** Menor investimento inicial
- **ROI:** ~35% a.a.
- **Payback:** ~4 anos

**🟡 Geração Consciente (130%)** ⭐ RECOMENDADO
- **Target:** Maioria dos consumidores
- **Característica:** Equilíbrio entre geração e investimento
- **Vantagem:** Margem para variações de consumo
- **ROI:** ~40% a.a.
- **Payback:** ~3-4 anos

**🔴 Geração Acelerada (145%)**
- **Target:** Consumidores com crescimento previsto
- **Característica:** Máxima geração e excedentes
- **Vantagem:** Preparado para aumento de consumo
- **ROI:** ~45% a.a. (considerando crescimento)
- **Payback:** ~3 anos

### 💰 Estrutura de Custos

#### Composição de Preço Total

**1. Custo do Kit (Base)**
- Painéis: 40-50%
- Inversor: 20-30%
- Estrutura: 10-15%
- Cabos/Proteções: 5-10%
- Acessórios: 3-5%

**2. Instalação (15-25% do kit)**
- **Simples (15%):** Telhado cerâmico plano, fácil acesso
- **Moderada (20%):** Altura média, estrutura padrão
- **Complexa (25%):** Altura elevada, estrutura especial, laje

**3. Manutenção (0,4-0,7% a.a.)**
- **Preventiva (0,3-0,5%):**
  - Limpeza painéis: 2-4x/ano
  - Inspeção visual: trimestral
  - Verificação elétrica: semestral
  
- **Corretiva (0,1-0,2%):**
  - Substituição componentes
  - Reparos estruturais
  - Correções elétricas

**4. Seguros (0,4-0,7% a.a.)**
- **RD - Riscos Diversos (0,3-0,5%):**
  - Cobertura: danos painéis, inversor, estrutura
  - Eventos: vendaval, granizo, raio, incêndio
  
- **RE - Responsabilidade Civil (0,1-0,2%):**
  - Cobertura: danos a terceiros
  - Eventos: queda painéis, incêndio, danos materiais

### 📈 Análise de Retorno

#### Cálculo de ROI (Kit 5 kWp Residencial)

**Premissas:**
- Consumo médio: 650 kWh/mês
- Tarifa média: R$ 0,85/kWh
- Geração média: 700 kWh/mês (130%)
- Investimento total: R$ 27.000

**Economia Anual:**
```
Economia Mensal = 650 kWh × R$ 0,85 = R$ 552,50
Economia Anual = R$ 552,50 × 12 = R$ 6.630,00

ROI = (R$ 6.630 / R$ 27.000) × 100 = 24,6% a.a.

Payback = R$ 27.000 / R$ 6.630 = 4,07 anos
```

**TIR (Taxa Interna de Retorno) - 25 anos:**
```
Fluxo de Caixa:
Ano 0: -R$ 27.000 (investimento)
Anos 1-25: +R$ 6.630 (economia anual)

TIR = 23,8% a.a.
VPL (6% desconto) = R$ 58.420
```

### 🏆 Garantias Padrão

#### Painéis Fotovoltaicos
**Garantia de Produto:** 12-15 anos
- Defeitos de fabricação
- Problemas estruturais
- Delaminação, quebra de células

**Garantia de Performance:**
- **10 anos:** ≥ 90% potência nominal
- **25 anos:** ≥ 80% potência nominal
- **Linear:** degradação ≤ 0,55% a.a.

#### Inversores
**Garantia Padrão:** 5-10 anos (conforme fabricante)
- Defeitos de fabricação
- Componentes eletrônicos
- Software/firmware

## 🔧 Compatibilidades e Restrições

### Compatibilidade Painéis x Inversores

#### Verificações Obrigatórias

**1. Tensão DC**
```
Voc_painel × N_painéis_serie ≤ Vmax_inversor

Onde:
- Voc_painel = Tensão circuito aberto (painel)
- N_painéis_serie = Quantidade painéis em série
- Vmax_inversor = Tensão máxima entrada inversor
```

**2. Corrente DC**
```
Isc_painel × N_strings ≤ Imax_mppt

Onde:
- Isc_painel = Corrente curto-circuito (painel)
- N_strings = Quantidade de strings paralelas
- Imax_mppt = Corrente máxima por MPPT
```

**3. Potência DC/AC**
```
1,0 ≤ (Potência_painéis / Potência_inversor) ≤ 1,3

Recomendado: 1,15 - 1,25 (oversizing 15-25%)
```

**4. Faixa MPPT**
```
Vmpp_min ≤ (Vmpp_painel × N_serie) ≤ Vmpp_max

Em operação normal de temperatura
```

#### On-Grid

**Obrigatório:**
- Controlador de carga MPPT

- Sistema backup (gerador opcional)

**Recomendado:**
- Baterias lítio (maior vida útil)
- Monitoramento SOC (State of Charge)
- Alarmes descarga profunda

#### Híbrido
**Obrigatório:**
- Inversor híbrido certificado
- Bateria compatível (tensão/comunicação)
- Sistema gerenciamento (EMS)
- Proteções AC/DC isoladas

**Recomendado:**
- Gateway monitoramento
- Medidor bidirecional inteligente
- Backup automático configurado

- Lajes sem avaliação estrutural
