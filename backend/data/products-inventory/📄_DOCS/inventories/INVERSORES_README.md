## 📚 SOBRE ESTA DOCUMENTAÇÃO

Esta é a documentação completa 360º de **Inversores Solares Fotovoltaicos** disponíveis no inventário YSH B2B. Cobre 12 fabricantes principais, 3 categorias de inversores (String, Micro, Híbridos), totalizando **5.800+ SKUs** de 5 distribuidores nacionais.

### Objetivo

Fornecer à equipe comercial, técnica e operacional do YSH uma referência única, completa e atualizada sobre todos os inversores disponíveis para venda, incluindo:

- Especificações técnicas detalhadas
- Comparativos de performance e custo
- Argumentos de venda por fabricante
- Matrizes de seleção por aplicação
- Preços, disponibilidade e lead times
- Certificações e conformidades

## 🎯 QUANDO USAR CADA DOCUMENTO

### Cenário: Atendimento Cliente Telefone/Chat

1. **Cliente pergunta:** "Qual inversor para sistema 5kW residencial?"
   - **Use:** `INVERSORES_QUICK_REFERENCE.md` → Seção "Seleção Rápida por Aplicação"
   - **Resposta rápida:** Deye (budget), Growatt (balanceado), Huawei (premium)

2. **Cliente pergunta:** "Qual melhor custo-benefício?"
   - **Use:** `INVERSORES_INDEX.md` → Top 5 Rankings → Por Custo-Benefício
   - **Resposta:** Growatt MIN (⭐⭐⭐⭐⭐)

3. **Cliente objeta:** "Growatt é chinês, não confio"
   - **Use:** `INVERSORES_QUICK_REFERENCE.md` → Argumentos de Venda → Growatt
   - **Resposta:** "#1 global vendas, 14 anos mercado, INMETRO certificado..."

### Cenário: Preparação Proposta Comercial

1. **Coletar informações cliente**
   - **Use:** `INVERSORES_QUICK_REFERENCE.md` → Checklist Pré-Venda
   - **Ação:** Preencher checklist completo

2. **Dimensionar sistema**
   - **Use:** `INVERSORES_QUICK_REFERENCE.md` → Calculadora Rápida
   - **Ação:** Calcular potência inversor ideal

3. **Montar 3 opções (budget/balanceado/premium)**
   - **Use:** `INVERSORES_INDEX.md` → Comparativos Rápidos
   - **Ação:** Copiar tabela comparativa

4. **Buscar especificações técnicas detalhadas**
   - **Use:** `INVERSORES_CONSOLIDADO_360.md` → Seção fabricante específico
   - **Ação:** Copiar specs para proposta

5. **Validar disponibilidade e lead time**
   - **Use:** `INVERSORES_CONSOLIDADO_360.md` → Seção Logística
   - **Ação:** Confirmar estoque e prazo

### Cenário: Validação Técnica Projeto

1. **Verificar compatibilidade MPPT**
   - **Use:** `INVERSORES_CONSOLIDADO_360.md` → Specs técnicas modelo
   - **Validação:** Tensão MPPT vs string painéis

2. **Conferir certificações**
   - **Use:** `INVERSORES_CONSOLIDADO_360.md` → Requisitos Técnicos
   - **Ação:** Verificar INMETRO, IEC 61727, NBR 16149

3. **Comparar TCO 25 anos**
   - **Use:** `INVERSORES_CONSOLIDADO_360.md` → Comparativos → TCO
   - **Análise:** Qual menor custo total propriedade

### Cenário: Treinamento Equipe Comercial

1. **Onboarding novo vendedor**
   - **Use:** `INVERSORES_README.md` (este arquivo) → Estrutura
   - **Depois:** `INVERSORES_QUICK_REFERENCE.md` completo

2. **Reciclagem time vendas**
   - **Use:** `INVERSORES_QUICK_REFERENCE.md` → Argumentos de Venda
   - **Prática:** Role-play objeções comuns

## 👥 PÚBLICOS-ALVO

### Equipe Comercial (Vendedores, SDRs, BDRs)

**Documentos principais:**

- ⭐ `INVERSORES_QUICK_REFERENCE.md` (80% do uso)
- 🔍 `INVERSORES_INDEX.md` (15% do uso)
- 📖 `INVERSORES_CONSOLIDADO_360.md` (5% do uso - consulta pontual)

**Workflows:**

1. Recebe lead → Consulta Quick Reference → Qualifica
2. Cliente interessado → Monta proposta 3 opções
3. Cliente objeta → Usa argumentos venda
4. Fecha venda → Registra CRM

### Equipe Técnica (Engenheiros, Projetistas)

**Documentos principais:**

- ⭐ `INVERSORES_CONSOLIDADO_360.md` (70% do uso)
- 🔍 `INVERSORES_INDEX.md` (20% do uso)
- 📖 `INVERSORES_QUICK_REFERENCE.md` (10% do uso)

**Workflows:**

1. Recebe projeto → Dimensiona sistema
2. Valida MPPT → Consulta specs técnicas
3. Confere certificações → Valida conformidade
4. Aprova projeto → Envia para comercial

### Equipe Operacional (Compras, Estoque, Logística)

**Documentos principais:**

- 🔍 `INVERSORES_INDEX.md` (50% do uso)
- ⭐ `INVERSORES_CONSOLIDADO_360.md` → Logística (40% do uso)
- 📖 `INVERSORES_QUICK_REFERENCE.md` → Preços (10% do uso)

**Workflows:**

1. Recebe pedido → Verifica disponibilidade
2. Sem estoque → Consulta distribuidores alternativos
3. Planeja compra → Valida lead times
4. Negocia preços → Usa tabela referência

### Gestão & Diretoria

**Documentos principais:**

- 🔍 `INVERSORES_INDEX.md` → Rankings (60% do uso)
- ⭐ `INVERSORES_CONSOLIDADO_360.md` → Resumo Executivo (30% do uso)
- 📖 `INVERSORES_CONSOLIDADO_360.md` → TCO & ROI (10% do uso)

**Workflows:**

1. Análise mercado → Top 5 rankings
2. Decisão estratégica → TCO 25 anos
3. Negociação distribuidores → Volume SKUs
4. Planejamento estoque → Disponibilidade
