🚀 COMO EXECUTAR
═══════════════════════════════════════════════════════════════════════════════

PASSO 1: Configurar Credenciais (2 min)
────────────────────────────────────────
  export AWS_ACCESS_KEY_ID=sua_chave
  export AWS_SECRET_ACCESS_KEY=seu_segredo
  export AWS_REGION=us-east-1
  export FACEBOOK_TOKEN=seu_token
  export FACEBOOK_CATALOG_ID=716960371408497


PASSO 2: Testar Conectividade (2 min)
──────────────────────────────────────
  node scripts/test-connectivity.js
  node scripts/verify-aws-setup.js


PASSO 3: Abrir Dashboard (em novo terminal)
────────────────────────────────────────────
  node scripts/upload-dashboard.js


PASSO 4: Executar Upload Maestro (15 min)
──────────────────────────────────────────
  node scripts/upload-to-aws.js
  
  Isto irá:
  • Fazer upload de 937 imagens para S3
  • Fazer upload de 3.337 SKUs para DynamoDB
  • Gerar relatórios JSON
  
  Arquivos gerados:
  • S3_UPLOAD_REPORT.json
  • DYNAMODB_UPLOAD_REPORT.json
  • AWS_UPLOAD_COMPLETE.json


PASSO 5: Sincronizar com Facebook (30 min)
───────────────────────────────────────────
  node scripts/sync-facebook-from-aws.js
  
  Isto irá:
  • Ler URLs de S3_UPLOAD_REPORT.json
  • Ler SKUs do DynamoDB
  • Sincronizar 3.337 produtos com 3 plataformas Meta
  
  Arquivo gerado:
  • FACEBOOK_SYNC_FROM_AWS.json

❌ TROUBLESHOOTING RÁPIDO
═══════════════════════════════════════════════════════════════════════════════

  Erro: "AWS credenciais não configuradas"
  └─ Solução: export AWS_ACCESS_KEY_ID=sua_chave

  Erro: "S3 bucket não encontrado"
  └─ Solução: aws s3 mb s3://ysh-b2b-products --region us-east-1

  Erro: "Produtos não aparecem no Facebook"
  └─ Solução: Aguarde 1-2 horas ou verifique FACEBOOK_SYNC_FROM_AWS.json

  Erro: "DynamoDB rate limited"
  └─ Solução: Aumentar write capacity units da tabela
